# ByteCycle: An 8-bit CPU Emulator

**ByteCycle** is a carefully engineered emulator for a custom-designed 8-bit CPU architecture written in C++.  
It serves as an educational tool for learning low-level computing concepts and CPU design.

---

## 🙏 Acknowledgements

**ByteCycle** is heavily inspired by [NanoCore](https://github.com/AfaanBilal/NanoCore) by [Afaan Bilal](https://github.com/AfaanBilal).

NanoCore is an excellent 8-bit CPU emulator + assembler + TUI debugger in Rust, and this project borrows ideas from its
architecture, ISA design, and overall educational focus.

---

## 📖 Introduction

**ByteCycle** operates on a minimal 8-bit architecture featuring:

1. **256 bytes** of addressable memory  
2. **8-bit registers**  
3. **8-bit Program Counter (PC)**  
4. **8-bit Stack Pointer (SP)**  

This constrained CPU architecture helps explore core fundamentals such as:

- CPU microarchitecture and cycles
- Instruction set design
- Memory addressing modes
- Stack operations
- Assembly language programming
- Emulator design & debugging

---

## 🎯 Project Goals

- Teach low-level architecture fundamentals  
- Create a clean and readable emulator codebase  
- Provide an approachable learning project for beginners  
- Explore opcode execution cycles → hence the name **ByteCycle**
